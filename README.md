# Personal Expense Tracker

Name: Syeda Rida Fatima
Registration No: CX-INT-2026-PY-0362

## Description
A command-line Python application that helps track daily expenses.
Users can add expenses with a category, view all expenses in a table,
see a category-wise spending summary, filter expenses by category,
delete an expense, and save/load data from a file so nothing is lost
between sessions.

## Features Implemented
- Add new expense (with description, amount, category)
- View all expenses in a formatted table with total
- Category-wise spending summary with percentages
- Filter expenses by category
- Delete an expense by ID (with confirmation)
- Save and load expenses from a text file automatically
- Input validation (rejects invalid/negative amounts, invalid menu choices)
